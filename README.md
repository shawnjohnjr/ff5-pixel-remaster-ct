## 使用方式

1. 備份存檔，啟動遊戲並讀取存檔，停在地圖上。
2. 在 Cheat Engine 連接 `FINAL FANTASY V.exe`，開啟需要的 CT。
3. 勾選一次，重新開啟遊戲選單確認結果。確認後另存新欄位。

取消勾選不會撤回修改。CT 為一次性修改，不會持續鎖定。版本檢查不通過時會停止。

## 職業與角色等級

`Level99` 提升角色等級，不提升職業。`JobABP` 只寫入現有職業的 ABP，不直接設定職業等級，也不操作能力或指令清單。自由人不需要 ABP，未解鎖職業不會新增。

`JobABP` 的預期流程：勾選後，讓各角色轉成需要提升的職業並贏一場有 ABP 獎勵的戰鬥，由遊戲處理升級和技能學習。其他職業需逐一轉職後戰鬥；後續解鎖新職業可再執行 CT。這個流程**尚未完成實際戰鬥驗證**，請先用備份存檔確認。

新版職業 CT 不呼叫 `mono_invoke_method` 或遊戲的升級／轉職函式。使用 Cheat Engine 的 Mono data collector 讀取類別資訊、檢查所有欄位及目前值後，僅寫入 `OwnedJobSaveData.currentProficiency`。若寫入檢查失敗，會嘗試還原本次已改的 ABP。未通過驗證的即時 MASTER 測試表不在此儲存庫中。
