## 使用方式

1. 備份存檔，啟動遊戲並讀取存檔，停在地圖上。
2. 在 Cheat Engine 連接 `FINAL FANTASY V.exe`，開啟需要的 CT。
3. 金錢、裝備與角色等級 CT：勾選一次，重新開啟遊戲選單確認結果。確認後另存新欄位。
4. ABP CT：選好四人目前要練的職業，勾選後贏一場有 ABP 獎勵的戰鬥，關閉結算回到地圖，再查看職業與能力選單。取消勾選即可恢復原本 ABP 倍率。之後可換職業再開啟、戰鬥。

取消勾選不會撤回已取得的金錢、裝備、等級、魔法或能力；ABP CT 的取消勾選會恢復啟用前的獎勵倍率。版本檢查不通過時會停止。關閉 Cheat Engine 前請先取消勾選 ABP CT。

## 職業與角色等級

`Level99` 提升角色等級，不提升職業。`ABP10000` 只調整遊戲的戰鬥 ABP 獎勵倍率，讓遊戲在正常戰鬥結算時同步升級和學習能力。一次戰鬥影響四人當前職業，不會直接把其他職業改滿，也不會解鎖劇情中尚未取得的職業。自由人沒有要用 ABP 提升的職業能力。

已驗證：原本只有 1 ABP 獎勵的戰鬥，在倍率啟用後顯示 10,000 ABP。戰鬥結算與能力選單均確認新能力正常取得，四名角色目前職業的完整能力清單也已核對。倍率從 1 提升至 10,000，測試結束後恢復為 1。

新版職業 CT 不呼叫 `mono_invoke_method` 或遊戲的升級／轉職函式，也不修改角色的技能清單或現有 ABP。它使用 Cheat Engine 的 Mono data collector 檢查類別資訊，僅寫入 `CheatSettingsData.abpRate`。取消勾選時會重新定位目前的設定物件並恢復原倍率。

### 舊版 JobABP 已撤換

舊版 `FF5_PR_JobABP_20265087.CT` 直接把職業 ABP 寫至滿級門檻，實測會顯示 MASTER，但可能缺少能力；已從目前版本撤下，請勿繼續使用。若已使用舊版且出現這種情況，讀取修改前的存檔，再使用新版戰鬥倍率 CT。不要把只有 MASTER 字樣、但能力不完整的狀態當作成功。

## 裝備包

包含諸神黃昏、正宗、飛龍之槍、巫師棒、緞帶、源氏系列、赫耳墨斯之靴等。Mirage Vest 的遊戲繁中名稱為**幻影背心**，補至 **4 件**。裝備加入背包，請依職業自行穿戴。

勇者利劍與弱雞匕首的效果仍依遊戲的逃跑紀錄計算；此表不修改逃跑次數。

存檔備份、私人資料、測試紀錄及失敗測試腳本皆不包含在版本庫內。

## 魔法 CT

七個項目彼此可分開勾選，檔案預設全部未勾選。每次只啟用需要的一類，請在地圖上執行，重新開啟選單確認後另存新欄位。

| 項目 | 招數 | 需已解鎖的職業 |
|---|---:|---|
| 白魔法 | 18 | 白魔導士 |
| 黑魔法 | 18 | 黑魔導士 |
| 時空魔法 | 18 | 時魔導士 |
| 召喚魔法 | 15 | 召喚士 |
| 青魔法 | 30 | 青魔導士 |
| 魔法劍 | 18 | 魔法劍士 |
| 歌曲 | 8 | 吟遊詩人 |

魔法以已學會的方式取得，不是加入道具背包。CT 使用遊戲的魔法取得與同步流程，跳過原本已持有的魔法，核對所選類別的魔法與能力記錄，並確認原有魔法、能力及已解鎖職業仍保留。它不直接設定職業等級，也不新增未解鎖職業。未解鎖職業的項目會顯示錯誤並停止取得流程。

學會全部魔法仍需對應的職業指令與能力等級才能使用；魔法劍、青魔法及歌曲可由對應的戰鬥指令查看。遊戲正常取得流程可能同步相關能力；獨立勾選不代表改寫遊戲原有的魔法關聯規則。取消勾選不會忘記已取得的魔法。

### 魔法驗證範圍

- 單招白魔法 Libra：魔法與能力記錄核對通過，使用者確認選單有出現且操作正常。
- 白魔法與黑魔法：各 18 招的魔法、能力記錄核對通過，原有能力與已解鎖職業保留；使用者確認遊戲正常、能開啟魔法選單。未逐招施放驗證。
- 當時未解鎖的時空、召喚、魔法劍、歌曲：四項停止保護均通過，魔法、能力及職業記錄沒有變動。這四類的實際取得流程尚未實測。
- 青魔法：尚未套用或實測。
- 最後一次額外唯讀檢查發生 Mono 連線逾時，已停止該檢查；使用者隨後確認遊戲仍正常。不能據此宣稱所有類別都已完整驗證或完全沒有 bug。
